## 2. P1 — Standalone Windows stability evidence verifier

**Defect:** Windows `stability` job ran `python tools/qt_stability.py --repeats 15` then `python tools/qt_evidence.py qt-logs/stability --write --repeats 15`. The latter expects a full archive (`collection.txt`, `versions.txt`, `summary.txt` at root, nested `stability/`), so it always failed on `qt-logs/stability` even when the 30 attempts passed.

**Fix:** New `tools/qt_stability_evidence.py` validates `qt-logs/stability` directly:

1. `manifest.json` parses and `manifest.sha256` matches bytes
2. `versions` contains `python` and, when claimed PASS, `pyside`/`qt`
3. Exactly the two historic nodes, no extras
4. Each node has 15 records, ordinals `1..15` exactly once in order
5. Each `attempt-*.txt` exists, non-empty where transcript expected, `bytes`/`sha256` match manifest
6. Header `ordinal=… node=… exit=… duration_s=… reason=…` matches manifest `ordinal`/`exit`/`reason`/`duration_s`/`log`/`sha256`
7. `summary.txt` counts reconcile (`stability attempts: 15`, `stability failed: 0`, `stability nodes: 2`, `stability nodes failed: 0`, `stability result: PASS`, per-node sections)
8. No `skipped`, `spawn_error`, abort signature in a claimed PASS
9. No silent retry/overwrite (ordinals unique, `RETRY` not allowed)
10. Empty directory never passes (fails with “empty”)
11. Any missing/duplicate/extra/corrupt/unknown fails the gate

**Runner-spawn hardening:** `tools/qt_stability.py` now wraps `workbench._run_node` in `try/except (OSError, RuntimeError, ValueError)`, records `spawn_error` with `exit 127` and `reason=spawn_error`, writes a header, and continues the remaining planned attempts. A later success cannot erase the earlier `spawn_error`. Direct verification: `tools/qt_workbench.py::_run_node` was also made cross-platform (`xvfb-run` if available and not Windows, else direct).

**Tests:** `tests/unit/test_qt_stability_evidence.py` 8 tests: valid PASS (2 repeats), missing log, duplicate ordinal, corrupted hash, extra file, reordered ordinals, empty directory, missing manifest — all use temporary directories with deliberate faults.

## 5. P1 — Baseline comparability and empty-denominator semantics

**Comparability contract `tools/coverage_report.py::_baseline_comparable`:**

- `measurement_scope` must match
- Exact `test_selection` (normalized) must match; legacy `unknown` is not comparable
- `schema_version` must match if baseline has one
- For `ui-test-selection`: `optional_dependencies.ui.present` must match exactly; `None`/missing is not comparable (both directions, not only headless→Qt)
- `runtime` Python version (`CPython 3.11` vs `3.14`) and `platform` (`Linux` vs `Windows`) must match for `ui-test-selection`
- Coverage runtime version if it changes interpretation
- Commit/SHA is recorded but different commits with same selection are comparable (delta is valid)
- Unknown state is unknown, not false

Output states exact reason, e.g. `test_selection differs: baseline 'X' != measurement 'Y'` or `Qt/UI optional dependency presence differs: baseline present=False vs measurement present=True`, and omits numeric delta.

**Empty denominator:** `FileCoverage`/`GroupCoverage.line_percent`/`branch_percent` now return `None` for zero `statements`/`branches`. `as_dict()` serializes `line_percent: None`, `branch_percent: None`, `present: false`, `measurement_state: "not_measured"`. Markdown via `_format_percent` shows `— (not measured)`, not `100%`. Machine-readable JSON never has false `100.0`.

Distinguishes:

- Zero statements: `None`, `present false`, `not_measured`
- Zero branches: `branch_percent None`, `line_percent` may still be measured
- Measured 0 hits: `0.0%`, `present true`, `measured`
- Absent package: not in view
- Present with no executable statements: `None`

**Missing XML:** `main()` default is strict: `no coverage XML at ...; nothing was measured` on stderr, `::error::required coverage XML is missing`, exit `2`. Diagnostic mode `--allow-missing` exits `0`. Required CI path uses strict (default). `test_cli_exit_when_xml_missing` now asserts `2` then `0` with `--allow-missing`. Artifacts use `if-no-files-found: error` for required reports.

**Tests:** `tests/unit/test_coverage_report_v20.py` 14 tests cover the matrix (same selection comparable, different selection not, Qt absent→present not, reverse not, unknown not, platform/python not, full vs UI not, legacy not, schema mismatch not, comparable improvement/negative delta, mismatched no arrow) plus empty-denominator null vs 0.0 and missing-XML strict.

**Schema:** `SCHEMA_VERSION = 3` (was 2) because `line_percent`/`branch_percent` type changed and `present`/`measurement_state`/`test_selection_fingerprint`/`platform`/`python_version`/`coverage_version` added.
