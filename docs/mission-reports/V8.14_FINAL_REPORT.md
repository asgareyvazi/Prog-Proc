## Windows open-file skip

The skipped test is `test_a_stale_connection_after_a_move_is_refused_and_recreates_nothing`. It tries to move a workspace folder while SQLite still has the database open, then proves a later write does not recreate a file at the old path. Windows returns `PermissionError` / WinError 32, so that scenario cannot be staged. The skip reason stays `this platform will not move an open database file`. It is not a pass.

The refusal itself is tested by renaming the open database file, not by
`shutil.move` of the parent folder. A Windows run of the folder move copied
into the destination before raising, so that shape does not prove the
application created nothing. A refused `Path.rename` leaves the original
file and does not create the destination. On a platform that allows the
rename, the test puts the file back and does not skip. Closing the workspace
and then moving the folder remains the supported move.

The Windows process-handle counter is also not a leak measurement. On
`e710732`, CPython 3.11 grew from 176 to 187 during the extract loop, after
an earlier run grew by 3. The test now skips on Windows with
`Windows process handle count is not a file-descriptor leak measurement`.
