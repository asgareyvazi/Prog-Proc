**تاریخ گزارش:** 2026-11-01 (Asia/Tehran)<br>
**شاخه مجاز:** `arena/5957b76d-prog-proc`<br>

**وضعیت این گزارش:** پیاده‌سازی فازهای 1 تا 8 انجام شده؛ پذیرش exact-SHA برای اصلاحات نهایی هنوز در انتظار اجرای CI است. تا آن زمان محصول «کاملاً qualified» اعلام نمی‌شود.

## خلاصه اجرایی

V10.3 در محدوده local-first تکمیل شده است: اصلاح مهاجرت‌ها و زنجیره عمر درس‌ها، run card ویندوز، صف محلی intake، هم‌ترازی ماتریس قابلیت‌ها، تقویت آزمون‌های lifecycle/worker، مستندسازی پذیرش و بسته‌بندی Pre-Alpha. هیچ provider هوش مصنوعی، embedding، Skills runtime، محاسبه یا نویسنده دامنه جدید اضافه نشده است.

در qualification انتهایی روی `f70bbbc`، سوئیت‌های اصلی Linux CPython 3.14 و Windows CPython 3.11/3.14 سبز شدند، اما اجرای سراسری CI سبز نشد:

- Linux CPython 3.14: **2637 passed, 55 skipped**؛ اسکیپ‌ها حفظ و شمرده شده‌اند، نه PASS.
- Windows CPython 3.11: **2635 passed, 57 skipped**.
- Windows CPython 3.14: سوئیت کامل PASS.
- Linux CPython 3.11 قبل از pytest در کنترل drift پین‌های `constraints/audit.txt` متوقف شد (`filelock` و `platformdirs`). پین audit با ابزار رسمی پروژه نوسازی شده است.
- آزمون‌های Qt روی Linux/Windows و Ubuntu 26.04 شکست داشتند: سه assertion قدیمی به شماره ردیف ثابت navigation متکی بودند و با اضافه شدن Intake دیگر درست نبودند؛ آزمون worker فهرست Intake نیز deadline پنج‌ثانیه‌ای را رد کرد. assertionها اکنون برچسب‌محور شده‌اند و deadline همچنان bounded و 15 ثانیه است؛ اجرای آتی exact-SHA باید این اصلاح را تأیید کند. اجرای محلی Qt به‌علت نبود `libGL.so.1` **SKIPPED** است و تأیید نمایشگر واقعی محسوب نمی‌شود.
- آزمون رفتاری Windows PowerShell 5.1 همچنان FAIL بود و PowerShell 7 در پی آن اجرا نشد. دانلود log/artifact از GitHub در این محیط با EOF روی میزبان ذخیره‌سازی artifact ممکن نشد؛ workflow اصلاح شده تا exception واقعی را در annotation و summary ثبت کند. ریشه شکست تا اجرای دوباره **تأییدنشده** است؛ این عدم قطعیت PASS تلقی نمی‌شود.

مراجع اجراهای تشخیصی روی SHA `f70bbbc`: Linux CI `41280028933`، Windows CI `41280029039`. این اجراها **قبول نهایی نیستند**. اجرای exact-SHA پس از انتشار اصلاحات انتهایی، شرط بستن گزارش است.
