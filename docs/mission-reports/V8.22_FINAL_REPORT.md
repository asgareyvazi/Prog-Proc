In V8.21 the test was left **without** `ui` marker and without `importorskip`, but the headless job did not fail because the test was not among the 5 that were marked `ui`? Actually V8.21 listed it as pure and not marked `ui`, but `WorkerError` still required Qt, so it should have failed headless. Direct evidence was missing.
