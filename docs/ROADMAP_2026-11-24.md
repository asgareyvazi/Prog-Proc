# Roadmap — 2026-11-24 (branch `arena/5957b76d-prog-proc`)

Dependency-ordered releases. "Owner-gated" items need an authorized engineering
owner decision packet; this project never invents their values. Every item lists
its acceptance gate; nothing ships as DONE before its gate passes.
